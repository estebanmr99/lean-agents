### Changed
- OpenCode 2 TUI edits use `cli.json` once the terminal client has written it; `tui.json(c)` stays the fallback only when `cli.json` is absent, and lean-agents never deletes `tui.json` (#558)
- On OpenCode 2, DCP stays in `opencode.jsonc` only: no TUI entry is added, and duplicate entries in `cli.json` or a stale `tui.json(c)` are removed on `--update` (the client's migration copies `tui.json`). The palette can still print the DCP panel row twice with DCP only in `opencode.jsonc` (the CLI loads the package's TUI entry for a server plugin); that remainder is upstream, with links in the docs (#558)
